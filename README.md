# LSAudio 工具

## Project setup

```
npm run  install
```

### Compiles and hot-reloads for development

```
npm run dev
```

### Compiles and minifies for production

```
npm run  electron:build
```

打包生成的安装程序 LSAudio Setup 1.0.0.exe 在 dist_electron 文件夹下

### Lints and fixes files

```
npm run  lint
```
